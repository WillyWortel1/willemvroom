Hypersail template

A reusable, content-neutral template in an editorial style: serif, ink on paper and a gold accent. Fill in one JSON file and get a PDF.

  • Dark cover with a large image, title with an italic line and key figures
  • Labels such as OFFICIAL, CLAIM and ESTIMATE
  • Numbered chapters, tables, boxes, timeline, videos and numbered sources
  • Dutch and English, fonts (open licence) included
  • Download the manual (PDF, Dutch)
  • Download the blank example (PDF, English)
  • Download the template (zip)

Requires Python 3 and Google Chrome or Chromium. All images in the template are neutral placeholders. As of October 2026.
